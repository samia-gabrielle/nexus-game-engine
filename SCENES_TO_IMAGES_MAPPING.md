## 📋 HOW TO USE THIS FOR IMAGE CREATION

### Step 1: Find the [IMAGEM: ...] description
Open the MD file, find the cena section, look for line starting with `[IMAGEM:`

**Example from SERA_CENA_1.md:**
```
[IMAGEM: Câmara Médica. Minimalista. Branca. Silenciosa.
Uma mulher em pé ao lado de uma máquina que pulsa cristal azul.
SERÁ. Cabelos pretos, olhos que viram demais, mãos que tremem levemente.
Ela não se vira quando você entra. Apenas continua observando o cristal.
Como se estivesse em luto por algo que ainda está vivo.]
```

### Step 2: Create AI prompt from description
Use this structure for Midjourney/DALL-E/Stable Diffusion:

```
[Character + appearance], [setting], [mood/lighting], [colors], 
cinematic, detailed, emotional, photorealistic, 1920x1080, 16:9, no text
```

**Example:**
```
Woman with black hair, distant gaze, standing in minimalist white medical chamber, 
blue pulsing crystal, melancholic mood, cold blue-white lighting, 
cinematic, detailed, emotional, photorealistic, 1920x1080 16:9
```

### Step 3: Organize by character
Create folders:
```
act5-images/
├── ivo/ (4 images)
├── sera/ (15 images)
├── thomas/ (12 images)
├── reva/ (15 images)
├── act5/ (10 images)
└── epilogue/ (1 image)
```

### Step 4: Name consistently
Use pattern: `character_scene_variant.png`

Examples:
- `sera_cena_1.png`
- `sera_cena_1_choice_a.png`
- `thomas_library_infinite.png`
- `harmony_ending.png`

### Step 5: Update HTML_INTEGRATION_GUIDE.md
Each scene definition needs `image` path:

```javascript
'sera_cena_1': {
    title: 'SERÁ - The Healer\'s Isolation',
    image: 'act5-images/sera/sera_cena_1.png',
    // ... rest of scene data
}
```
